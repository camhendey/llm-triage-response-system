# Illustrative importer fixtures

Invented values and headers for testing. These are **not genuine OpenTable exports** and do not establish its current CSV schema. No real guest data is included.

Reservations cover November 13–14, 2026. The guestbook deliberately includes a shared email and phone to verify that identity candidates are not automatically merged. Separate request/visit/guestbook note fields test provenance preservation. Source table numbers intentionally do not map to the synthetic seating layout.
