# Screenshot provenance

Sole developer: Cameron Hendey. Original workflow developed at JOEY in 2024; refined in 2025.

Current coordinator captures are in `coordinator/`, produced by `python scripts/verify_coordinator.py` using fictional records and an illustrative export. Request, Plan, Communicate and Service are captured with 820/390 px checks. Demo captures remain in `nicegui/`, produced by `python scripts/capture_nicegui.py`. These are actual application screenshots, not mockups. No real seating photo or guest records are supplied.

`clean/` shows Streamlit 1.2; `refined/` shows Streamlit 1.1. Files directly in this folder are original 1.0 captures. Historical capture scripts target the retained Streamlit entry point where compatible.
